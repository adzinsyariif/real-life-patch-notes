## What it does

`main.ts` writes a single line — a software patch note for a bug in real
life, in the terse register of a real release note — to `/output/entry.txt`.
The gate requires UTF-8 text of 1 to 160 characters, not only white space.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). No
dependencies, no network, no secrets.
